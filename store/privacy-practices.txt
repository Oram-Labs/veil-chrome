Single purpose description
------------------------------------------------------------------
Veil hides sensitive values, such as names, email addresses, phone numbers and card numbers, from messages and attached documents before claude.ai and chatgpt.com send them, and puts the real values back in the replies. Detection and replacement are done on the user's computer: by the Veil desktop app when it is installed, or by an engine built into the extension when it isn't.

------------------------------------------------------------------
nativeMessaging justification
------------------------------------------------------------------
When the Veil desktop app is installed and running, it does the redaction. The extension uses native messaging to send each outgoing message (and any attached document) on the protected sites to that app on the same computer, and to get back the redacted text and the values to restore in replies. It also asks the app whether it is running and which sites the user chose to protect. Native messaging is the only channel the extension uses for user content; nothing is sent to a server.

------------------------------------------------------------------
storage justification
------------------------------------------------------------------
chrome.storage.local keeps the user's per-site setting "Send without Veil when it isn't running", a cached copy of the latest Veil version number (so the popup can say when an update is available without checking on every open), and, for the extension's built-in engine, its settings and rules, activity counts (kinds and numbers of values hidden, never the values) and whether it is turned on. chrome.storage.session, which Chrome keeps in memory and empties when the browser closes, holds the count of hidden values per tab for the toolbar badge, which engine each chat used, and, for the built-in engine, which value each placeholder stands for (for example which email address is EMAIL_1 in a chat), so replies can be restored while the browser is open. Real values are never written to disk. Nothing is sent anywhere; the user can clear it from the extension's settings page ("Forget values now", "Delete everything").

------------------------------------------------------------------
Host permission justification
------------------------------------------------------------------
The extension runs only on https://claude.ai/* and https://chatgpt.com/*, the two AI chat sites it protects. On those pages it has to see each outgoing request before it is sent so it can replace sensitive values with placeholders, and see the replies so it can put the real values back. It does not run on, read or change any other site. The built-in engine runs only on these two sites too, and makes no network requests.

Are you using remote code?
------------------------------------------------------------------
Select: No, I am not using remote code.
Justification (if a field is still shown):
All code is bundled in the extension package, including a WebAssembly module (the open-source Veil redaction engine, compiled from public source) that the extension loads from its own files. The content security policy adds 'wasm-unsafe-eval' only so the browser may compile and run that bundled module; Chrome requires it for any WebAssembly in an extension. The extension does not load or run code from any server, and does not use eval or Function(). The only network request it makes itself is a GET of https://getveil.tech/download/latest.json, a JSON file with the latest version number, which is read as data and never run.

Data usage
------------------------------------------------------------------
Suggested: leave every data type unchecked. Message text and documents are handled on the user's device: they go only to the Veil app on the same computer or to the engine inside the extension, never to the developer or any third party. What the built-in engine keeps stays in the browser. The extension has no analytics, accounts or tracking.
